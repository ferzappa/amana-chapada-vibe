# Integrar feed do Instagram com Elfsight

## O que será feito
Substituir as imagens estáticas do Unsplash no rodapé por um widget Elfsight que exibe as últimas publicações reais do `@amanahotelchapada`.

## Passos

1. **Você cria uma conta gratuita no Elfsight** (elfsight.com) — leva ~2 minutos
2. Configura o widget Instagram Feed com o perfil `@amanahotelchapada`, escolhe layout grid 3×2
3. Copia o código embed (um `<script>` + `<div>`)
4. **Eu integro no Footer.tsx** — substituo o grid de imagens estáticas pelo componente embed do Elfsight

## Sobre o Elfsight
- **Plano gratuito**: ilimitado em tempo, com branding Elfsight
- **Plano Basic**: $5/mês, sem branding
- Atualiza automaticamente com novas publicações
- Não precisa de API key nem Facebook App
